# Practical-02
MLOps Experiment 02: Git Version Control
Objective

To understand Git installation, configuration, repository creation, branching, merging, collaboration, version history, and conflict resolution.

Tools Used
Git Bash
GitHub
Python
Project Files
train.py — ML training code
requirements.txt — project dependencies
.gitignore — files excluded from version control
README.md — project documentation
Version Control Workflow
Configure Git username and email.
Initialize the local repository using git init.
Track files using git add and save snapshots using git commit.
Create feature branches using git switch -c.
Merge branches using git merge.
Connect to GitHub using git remote add origin.
Upload changes using git push.
Collaborate through pull requests.
Inspect project history using git log.
Resolve merge conflicts and commit the corrected files.
Conclusion

Git and GitHub provide a reliable workflow for tracking ML source code, maintaining version history, and collaborating on MLOps projects.
